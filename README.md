# DeathBound

Fabric mod for Minecraft 26.3 (Java 25). Mod id `deathbound`.

```
./gradlew runClient    # play in a dev client
./gradlew build        # jar -> build/libs/DeathBound-1.0.0.jar
```

> Source restored from `DeathBound-1.0.0.jar` (Oct 7) with Vineflower, because the original source was not on this machine.
> Code, names and resources are identical to that jar; only comments and formatting from the original source are lost.
> If you have the original source at home, prefer it.
